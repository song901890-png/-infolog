다른 사이트는 잘 열리는데 **특정 사이트만 접속이 안 되는** 경우가 있습니다. 대부분은 브라우저 캐시, DNS 캐시, 일시적인 DNS 응답 오류처럼 간단한 원인에서 시작됩니다. 아래 순서대로 따라 하면 10분 안에 원인을 좁힐 수 있습니다.

<SoftCTA />

## 1단계: 문제 범위부터 진단하기

해결법을 고르기 전에 **어디에서 문제가 생겼는지**부터 확인해야 합니다.

| 확인 방법 | 결과 | 의미 |
| --- | --- | --- |
| 스마트폰 Wi-Fi 끄고 모바일 데이터로 접속 | 접속됨 | 집 공유기·통신사 DNS 문제 가능성 |
| 다른 브라우저(또는 시크릿 창)로 접속 | 접속됨 | 브라우저 캐시·확장 프로그램 문제 |
| 모든 기기·네트워크에서 접속 불가 | 접속 안 됨 | 사이트 자체 장애 또는 주소 변경 |

## 2단계: 브라우저 캐시·쿠키 삭제

오래된 캐시가 남아 있으면 이미 바뀐 페이지 대신 깨진 정보를 불러올 수 있습니다.

- **크롬(PC):** `Ctrl + Shift + Delete` → 기간 '전체' → "쿠키 및 기타 사이트 데이터", "캐시된 이미지 및 파일" 체크 → 삭제
- **크롬(모바일):** 설정 → 개인정보 보호 및 보안 → 인터넷 사용 기록 삭제
- **사파리(아이폰):** 설정 → 앱 → Safari → 방문 기록 및 웹 사이트 데이터 지우기

## 3단계: DNS 캐시 초기화

컴퓨터는 한 번 찾은 사이트 주소를 일정 시간 기억(캐시)합니다. 사이트 서버가 바뀌었는데 예전 주소를 기억하고 있으면 접속이 실패합니다.

**윈도우:** 명령 프롬프트(cmd)를 관리자 권한으로 열고 아래 명령어를 입력합니다.

```bash
ipconfig /flushdns
```

**macOS:** 터미널에서 아래 명령어를 입력합니다.

```bash
sudo dscacheutil -flushcache; sudo killall -HUP mDNSResponder
```

## 4단계: 공개 DNS로 변경하기

통신사 기본 DNS가 일시적으로 느리거나 오류가 날 때는 공개 DNS로 바꾸면 해결되는 경우가 많습니다.

| 제공사 | 기본 DNS | 보조 DNS |
| --- | --- | --- |
| Cloudflare | 1.1.1.1 | 1.0.0.1 |
| Google | 8.8.8.8 | 8.8.4.4 |
| Quad9 | 9.9.9.9 | 149.112.112.112 |

각 주소는 제공사 공식 안내([Cloudflare 1.1.1.1](https://developers.cloudflare.com/1.1.1.1/), [Google Public DNS](https://developers.google.com/speed/public-dns), [Quad9](https://www.quad9.net/))에서 직접 확인할 수 있습니다. 공식 문서에 없는 DNS 주소는 입력하지 마세요.

**윈도우 11:** 설정 → 네트워크 및 인터넷 → Wi-Fi(또는 이더넷) → 하드웨어 속성 → DNS 서버 할당 '편집' → 수동 → IPv4 켜기 → 기본/보조 DNS 입력

**안드로이드:** 설정 → 연결 → 기타 연결 설정 → 개인 DNS → '개인 DNS 제공자 호스트 이름'에 `one.one.one.one` 또는 `dns.google` 입력

**아이폰:** 설정 → Wi-Fi → 연결된 네트워크의 (i) → DNS 구성 → 수동 → 서버 추가

## 5단계: 그래도 안 된다면 — 가짜 주소 주의

주소가 바뀐 사이트를 검색하다 보면 **비슷한 이름의 가짜(피싱) 사이트**가 상위에 노출되기도 합니다. 아래 신호가 보이면 즉시 창을 닫으세요.

- 원래 주소와 철자가 한두 글자만 다른 도메인
- 접속하자마자 로그인·본인인증·앱 설치를 요구
- 브라우저 주소창에 "안전하지 않음" 경고 표시

문자·메신저로 받은 링크를 통한 피싱 수법은 [주간 이슈: 연말 피싱 문자 주의보](/weekly-issue-2026-11-w3/)에, 출처 불명 스트리밍 링크의 위험은 [합법 중계 플랫폼 고르는 기준](/sports-legal-streaming-checklist/)에 정리해 두었습니다. 피싱이 의심되면 [KISA 보호나라](https://www.boho.or.kr/)나 국번 없이 118로 신고할 수 있습니다.

> 참고: 법령에 따라 접속이 차단된 사이트(경고 안내 페이지로 연결되는 경우)는 기술적 오류가 아니므로, 이 글의 해결 방법 대상이 아닙니다.

## 마무리

**진단 → 캐시 삭제 → DNS 캐시 초기화 → 공개 DNS 변경** 순서로 진행하면 대부분의 접속 오류는 해결됩니다. 모든 단계를 거쳐도 안 된다면 사이트 쪽 문제일 가능성이 높으니, 공식 공지 채널을 확인하는 것이 가장 빠릅니다.
